# SUMANOVA

A real-time social communication app: chat, calls, snaps, stories, a 3D avatar studio, a social map and more.
It installs on Android as a PWA and runs on free tiers only.

## Branches

| Branch | Purpose |
| --- | --- |
| `main` | Production releases |
| `develop` | Integration branch; feature branches merge here through PRs |
| `release/1.0.0` | Stabilisation for the 1.0.0 release |
| `SUM-202601` | Current feature work (merges into `develop`) |
