SUMANOVA — AVATAR USER STORIES (prompt-style)
=============================================
Stories: sumanova-us-106 … sumanova-us-190  (17 parts × 5 stories = 85 stories)
Baseline: build-103 (12 starter characters, screenshot reviewed 2026-11-27)
Goal: every part of a SUMANOVA avatar must look and feel clearly better than a Bitmoji —
more detailed, more expressive, more inclusive, more editable — while staying 100% original.

-----------------------------------------------------------------------------------------
WHAT BUILD-103 SHOWS (the problems these stories fix)
-----------------------------------------------------------------------------------------
 - Hair reads as lumpy clay or a helmet (teal crop, pink long hair, black long hair); the
   hairline is a hard edge on the forehead; long hair looks like ropes, not flowing hair.
 - Faces are flat and orange-tinted; every character has the same open-mouth grin; the eyes
   are small and doll-like; there is little bone structure (cheekbones, brow, jaw).
 - Beards look like a dark mask stuck on the chin, not hair.
 - Bodies: big head, short torso, stiff "A-pose" arms, tiny hands with spread fingers,
   straight tube legs, tiny feet; every character stands the same way.
 - Clothes look like puffy padded shells: boxy pillow shoulders, no drape, odd white
   collar rings / plackets, white lines at the waist, the saree is a flat strip.
 - Glasses lenses render as opaque white; bags/hats/glasses are simple shapes.

-----------------------------------------------------------------------------------------
RULES FOR EVERY STORY (paste with any prompt)
-----------------------------------------------------------------------------------------
 - Original only: no Snapchat/Bitmoji assets, names, layouts, logos or yellow; no brands.
 - ₹0: free / open-source only; everything procedural or made in-house; no paid assets.
 - Smooth on a mid-range Android phone: geometry built in the worker (sculpt3d/async.ts),
   cached; keep per-avatar triangles within the agreed budget; reduce-motion and data saver
   respected; ≤ 8 canvases per harness page.
 - Saved avatars must keep working: never shift variant ids; extend normalizeLook() for any
   new field; old looks get sensible defaults.
 - Bump SCULPT_VERSION (sculpt3d/jobs.ts) when a builder output changes and snv-thumbs-vN
   (editor/thumbs.tsx) when the rendered look changes; re-render starter pictures
   (e2e/preset-images.e2e.cjs); re-run the duplicate checker (?dupes=<slot>) for new catalogues.
 - Verify visually in the harness (npx vite --config vite.avatar-test.config.ts, port 5199)
   with before/after screenshots; npm run typecheck, npm test, npm run build stay green.
 - New UI text → tools/i18n TSV line + rebuild (en/hi/kn/ta/te).
