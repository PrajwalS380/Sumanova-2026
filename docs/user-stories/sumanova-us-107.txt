=========================================================================================
sumanova-us-107 · Natural hairline, visible partings, baby hairs & laid edges
=========================================================================================

USER STORY
  As a SUMANOVA user, I want my avatar's hairline, temples and parting to look like real
  hair growing out of real skin — soft at the edge, with fine baby hairs, a visible scalp
  line where I part my hair, and the option of styled "laid" edges — so my avatar never
  looks like it is wearing a wig or a helmet, and looks more natural than any Bitmoji.

WHY (what build-103 shows)
  - The hair ends in a hard, raised step on the forehead and temples (clearest on the teal
    crop and the black short styles): the scalp layer is full thickness right up to the
    hairline and is cut straight off.
  - Partings (left / right / middle / zigzag) only change the comb direction; the locks
    still cover the part, so no scalp line is ever visible.
  - No fine baby hairs or styled edges; only curly/coily styles get a row of baby curls.
  - The user cannot move the hairline up or down, or choose how the edges are styled.

1) DATA MODEL — look/hair.ts
   a. Add `export type EdgeT = 'clean' | 'soft' | 'laid';`
        clean = crisp barber line-up, no baby hairs (still no hard step)
        soft  = natural thinning edge + a few fine baby hairs (DEFAULT for every style)
        laid  = soft edge + styled, swooped baby hairs flat on the forehead / temples
   b. Add `edges: EdgeT` to HairP and `edges: 'soft'` to the defaults object D. Do NOT edit
      the 110 recipes in LIB (ids must never shift); optionally set edges:'clean' on the
      barbered recipes where a line-up is the point (e.g. 'Buzz with line-up', 'Caesar cut').
   c. Extend HairTune with:
        line?: number   // −1 … 1  (lower … higher / receding hairline)
        edges?: EdgeT
   d. hairControls(p): add `line: !shaved` and `edges: !shaved` (shaved = p.fade === 'buzz').
      Edges must also be available for afros, puffs, coils and cornrows (laid edges are
      very common there).
   e. tuneHair(p, t): if c.line && t.line → q.line = clamp(p.line + t.line, −1, 1.2);
      if c.edges && t.edges → q.edges = t.edges.
   f. HAIR_OPTIONS.edges = ['clean', 'soft', 'laid'].
   g. normalizeHairTune(): accept `line` via num(r.line, −1, 1) and `edges` via
      pick(r.edges, EDGES). Unknown values are dropped (old saved looks stay valid).
   h. render/bakedHair.ts bakedHairId(): treat `tune.line` and `tune.edges` like the other
      shape changes (they force the live groom).

2) SOFT HAIRLINE — sculpt3d/groom.ts
   a. Scalp layer, baseCap() (~line 240): the cap is full thickness right at the hairline,
      which makes the step. Multiply the hair part of `thick(uy, az)` (not the afro volume
      term) by an edge taper:
          e = smooth(lineAt(az), lineAt(az) + band, uy)
          thick *= 0.2 + 0.8 * e
      band ≈ 0.10 unit-height for 'soft'/'laid', ≈ 0.05 for 'clean'. Keep the existing
      `below` clip so nothing grows under the hairline. Result: the cap thins smoothly to
      ~20 % at the edge — no visible ledge from front, 3/4 or side.
   b. Hairline density shell — new method edgeShell(), modelled on fadeShell() (~line 288):
      a thin shell (skullDist − 0.004·R) covering a band just BELOW and AT the hairline,
      uy ∈ [lineAt(az) − w, lineAt(az) + 0.03], all azimuths, skipping faded zones
      (this.faded) and the mohawk sides. Vertex colour .r = density:
          dens = smooth(lineAt(az) − w, lineAt(az), uy) * maxDens
      soft: w 0.06, maxDens 0.7 · laid: w 0.05, maxDens 0.8 · clean: w 0.025, maxDens 0.9.
      Render it with the existing clipper-stubble material (useStubbleMaterial in
      SculptHair.tsx: hair-coloured fine dots whose density follows vColor.r), so the
      hair thins into skin. Simplest wiring: in build(), merge edgeShell() into the 'fade'
      geometry with mergeGeometries (same attributes: position, normal, color); create the
      fade piece when only the edge shell exists. Skip the shell when hatOn and the hat
      covers the hairline.
   c. Hairline height: lineAt() already uses p.line (front lift = p.line * 0.1 and the
      temple recesses scale with 1 + p.line). Make sure the tuned p.line moves the whole
      front hairline (forehead + temple corners) visibly at ±1 without exposing the cap
      edge or letting fringe locks start below the brows (browY).

3) BABY HAIRS & LAID EDGES — groom.ts, new method edges(), called from build() after the
   main strands (skip when fade === 'buzz', when hatOn, and when braid === 'cornrows' for
   'soft'; cornrows still get 'laid').
   a. soft (straight / wavy / textured hair): ~36–48 baby hairs along the front and temple
      hairline, az from −1.25 to +1.25 rad, step ≈ 0.06 + jitter; root at
      uy = lineAt(az) + 0.005…0.02. Grow with this.grow(u, L, { fringe:false, layer:0.9,
      liftK:0.1 }) where L = 0.05…0.10 head radii; emit with w0 ≈ 0.012·R, flat 0.6,
      tip 0.05, radial 3. Must lie flat (no spikes) and never reach the brows.
      Curly / coily hair keeps the existing baby-curl row (scalpStrands ~line 596), but
      move that row into edges() so it is controlled by the same setting ('clean' = none).
   b. laid: 5–6 swoops per side at the temples and forehead corners
      (az0 ≈ ±0.30, ±0.50, ±0.70, ±0.90, ±1.10) + optional centre swoop. Each swoop is
      drawn directly on the skin, not grown: sample t ∈ [0,1] (12–16 points),
          az(t) = az0 + side · 0.16 · t
          uy(t) = lineAt(az0) + 0.01 − 0.05 · sin(0.9πt) + 0.02 · t²
          point = this.scalp(unitDir(az(t), uy(t)), this.cap * 0.15)
      and emit 4–6 parallel fine strands per swoop (offset 0.004·R, w0 ≈ 0.008·R,
      flat 0.9, tip 0.1) so it reads as a sleek S-wave of gelled hair. Laid edges must not
      overlap the eyebrows, eyes or ears.
   c. clean: no baby hairs; crisp edge from step 2 with the narrow density band.

4) VISIBLE PARTINGS — groom.ts
   a. Helper inPart(u, halfW): true when the style has a part (partX(z) not NaN), the root
      is on the top/front of the head (u.y > lineAt(az) + 0.02, u.y > 0.3, u.z > −0.3) and
      |u.x · rx − partX(root.z)| < halfW · R. halfW ≈ 0.045 (zigzag: follow the zigzag).
   b. scalpStrands() (~line 514): `continue` for roots where inPart(u, 0.045) — no lock
      roots inside the part.
   c. comb() (~line 326), flow 'side': today every root sweeps the same way, which buries
      the part. Roots on the small side of the part (sign(root.x − px) opposite to the
      sweep) and in the top zone (u.y > 0.2) must comb AWAY from the part
      (out.set(away·0.9, −0.5, 0.1)), like real side-parted hair.
   d. baseCap(): carve a narrow groove in the cap along the part so the real skin of the
      head mesh shows through: d = max(d, halfGap − |x − partX(z)|) inside the top-front
      zone, with halfGap ≈ 0.012·R tapering to 0 toward the crown
      (smooth over z/rz from −0.35 to −0.1) so the part ends naturally. Keep the field
      Lipschitz-safe (lipschitz already 1.4; raise only if holes appear —
      watertight.test.ts must pass).
   e. Optional: a very low-density stubble strip (density 0.25) along the part using the
      same shell technique as 2b, so the part reads as scalp with fine hair, not bald skin.

5) CROWN WHORL — groom.ts comb(), default flow with part 'none'
   Hair already radiates from the crown point (0, 0.85, −0.45). Add a gentle tangential
   swirl near it: out += cross(crownDir, u) · 0.6 · exp(−(angle(u, crownDir)/0.35)²).
   Clockwise by default; seed-based direction is fine. Must not create a bald spot.
