USER STORY
  As a SUMANOVA user of any background — Indian, African, South-East Asian, European,
  Latin, mixed — I want my exact hair texture (from straight to tight 4C coils) and the
  styles I actually wear (a long plait with a paranda, a jooda with gajra, bantu knots,
  twists, a silk press, a man bun with a fade…), so my avatar truly looks like me and no
  avatar app (including Bitmoji) represents my hair better.

WHY (what build-103 has today)
  - Texture is one of 5 words (straight / wavy / curly / coily / textured) plus one curl
    strength (HairP.curl). There is no way to say "my curls are 3B" or "my hair is 4C";
    curly and coily each look the same size on everyone.
  - Real curl shrinkage is missing: coily hair is as long as straight hair of the same style.
  - South-Asian everyday styles are thin: no paranda plait, no jooda with gajra, no oiled
    sleek plait, no plait over the shoulder, no school double plaits with ribbons.
  - Textured styles are limited: no bantu knots, finger coils, flat twists, short twists,
    TWA, pineapple puff, knotless / goddess / beaded braids, sisterlocks, frohawk.
  - The hair grid only filters by 6 categories; there is no quick "Textured" or
    "Indian" filter, and the search box says "Search 110 hairstyles" (hard-coded).

1) CURL-PATTERN SCALE — look/hair.ts + groom.ts texture()
   a. Add `export type CurlPattern = '1' | '2A' | '2B' | '2C' | '3A' | '3B' | '3C' | '4A' | '4B' | '4C';`
      and an optional `pattern?: CurlPattern` on HairP (recipes) and on HairTune (user).
   b. One table drives the groom (head-radius units R; tune by eye, keep in one place):
        pattern  tex      shape        radius   pitch    shrink  vol+   clump  notes
        1        straight none         —        —        1.00    0      1.00
        2A       wavy     S-wave       0.030    0.100    0.97    0.05   1.00   loose, mostly straight at root
        2B       wavy     S-wave       0.045    0.080    0.94    0.10   0.95   defined S from mid-length
        2C       wavy     S-wave+frizz 0.060    0.065    0.90    0.20   0.90   some loose spirals
        3A       curly    spiral       0.050    0.120    0.88    0.25   0.90   big loose loops
        3B       curly    spiral       0.035    0.080    0.80    0.35   0.80   springy ringlets
        3C       curly    spiral       0.025    0.055    0.70    0.45   0.75   tight corkscrews, dense
        4A       coily    spiral       0.018    0.035    0.60    0.55   0.70   defined coils
        4B       coily    zigzag       0.015    0.025    0.50    0.65   0.65   Z-pattern (triangle wave)
        4C       coily    zigzag       0.012    0.020    0.40    0.75   0.60   tight, less defined, max volume
      - radius = curl amplitude, pitch = length per turn; shrink multiplies the lock length
        (so a 4C style is visibly shorter than the same style in 1); vol+ adds to p.vol;
        clump multiplies p.clump.
      - 'zigzag' = triangle wave instead of sine in texture(); '+frizz' = a few extra
        fly-aways (reuse the existing fly-away code).
      - Keep the current height-based "coherent" waves for long 2x/3x hair (neighbouring
        locks in phase) — do not break the last commit's look for wavy long styles.
   c. Mapping when no pattern is set (old looks stay as they are): straight → 1,
      wavy → 2B, curly → 3B, coily → 4A, textured → unchanged (its own code path).
      With no pattern field the groom output must be byte-identical to today for ids 0–109
      (assert in a test by comparing vertex counts / hashes for a few styles).
   d. tuneHair(): t.pattern sets q.tex + q.curl + the table effects (only when
      hairControls(p).tex is allowed). normalizeHairTune() accepts only valid patterns.

3) NEW GROOM FEATURES NEEDED — sculpt3d/groom.ts (only what the 30 styles require)
   a. HairP.sleek (0…1): flattens locks to the scalp (low lift, wide flat locks, little
      messy), feeds a higher default gloss in SculptHair (oiled / pressed look).
   b. HairP.bevel (0…1): long straight ends curve slightly under (silk press).
   c. Ties: 'topknot' (tight high knot), 'bantu' (sectioned grid of small knots: draw
      shallow scalp partings between sections like cornrows do, each knot = a coiled lock
      wound into a cone), 'puff' (front lift section gathered back), 'pineapple' (crown puff
      of coils), 'bubble' (pony with periodic bands, the tail bulging between them).
   d. Braids: 'sideplait' (single plait path routed over one shoulder to the front, kept off
      the body with keepOffBody(preferFront = true)), 'looped' option for double braids
      (each plait folds back up and is tied behind the ear), 'knotless' flag for box braids
      (no root knot, root width ramps from 0), 'goddess' flag (each braid ends in a 3A curl
      lock), 'flattwist' (two-strand twist laid flat on the scalp like cornrows).
   e. Locs: 'micro' locs (sisterlocks) — many thin locs; keep the mesh light (≤ 4 radial
      segments, merged into one draw call, total ≤ the triangle count of 'Box braids').
   f. Decorations — HairP.deco: 'none' | 'paranda' | 'gajra' | 'ribbon' | 'beads', built as
      extra sculpted pieces in the 'band' geometry with a per-piece colour role:
        paranda = 3 tassels + pom-poms (colour hairDeco), gajra = jasmine buds (white with a
        cream centre, ignores hairDeco unless set), ribbon = bow loops + tails (hairDeco),
        beads = cylinder beads on braid ends (hairDeco, metallic option).
      Add 'hairDeco' to COLOR_KEYS (config.ts, nullable, default null → style default), and
      render the band pieces in SculptHair.tsx with that colour instead of the hard-coded
      '#ff6f61' (the plain hair-tie elastic keeps its current default when hairDeco is null).
      These decorations are part of the style; the general hair-accessory slot is us-110 —
      build the deco pieces so us-110 can reuse them.
